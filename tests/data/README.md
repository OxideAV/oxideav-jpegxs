# DWT ordering fixture

`dwt-ed3.txt` contains 798 whole-coefficient-grid fingerprints generated by
`reference-dwt.c` linked to the unmodified `libjxs/src/dwt.c` from the
[official ISO/IEC 21122-5 edition-3 software archive](https://standards.iso.org/iso-iec/21122/-5/ed-3/en/ISO_IEC_21122-5_ED-3.zip).
Archive SHA256: `36efc26b92a09b7447bc6e580c902d5c19ee9e919b324609768e390d38621835`.
The reference source itself is not included here.

Compile from this directory, with `REF` set to the extracted archive root:

```sh
cc -O2 -I "$REF/libjxs/src" -I "$REF/libjxs/public" reference-dwt.c "$REF/libjxs/src/dwt.c" -o reference-dwt
./reference-dwt > regenerated.txt
```

Compare the numeric rows, ignoring `#` metadata lines. Each row is width,
height, horizontal levels, vertical levels, source depth, fractional shift,
and FNV-1a-64 of every interleaved signed coefficient serialized little-endian.
The generator checks the reference inverse reconstructs every input sample.
The Rust regression independently maps its separate bands into that grid.
The hash is a compact regression fingerprint, not a cryptographic authenticity
claim. The accompanying literal 2×2 witness and signed-edge equation test
check the values directly.

Reference locations: `dwt_forward_transform`, `libjxs/src/dwt.c:160–175`;
`dwt_inverse_transform`, `:142–158`. All joint forward levels run vertical
before horizontal; inverse levels reverse that order. No normative Annex E
text is reproduced, and no reference implementation source is copied into
this patch.

The small/odd geometries exercise every source depth 8–16 at fractional shifts
0/6/8. The wider set covers every `(NLx, NLy)` with `1 <= NLx <= 8` and
`0 <= NLy <= NLx`, both dimension parities, depths 8/16 and shifts 0/6/8.
These are numerical cascade tests; they do not assert those deeper levels
are allowed by a named profile. The reference `ids_xy_val_t` fields are signed
four-bit: the driver represents level 8 by a one-level reference call followed
by seven reference levels on the LL grid, in reverse order for inverse.
